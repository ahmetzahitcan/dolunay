description: How to access tooling
---

Use AMD/Xilinx tooling.

If the host is running Windows: Tools are installed under `C:\AMDDesignTools\`.

If the host is running Fedora Linux: Tools are installed under `/home/azc/Xilinx/`, but they must be run with distrobox. Container name is `ubuntu-22-04`.

If you attempted to access the tooling, but failed to, report to user.
